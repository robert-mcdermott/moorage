About this handbook

The handbook is a directory of HTML files in the team's repository. Anyone on the team can change it: edit a page, open a pull request, and deploy it once it is merged.

Each page is a file: this one is public/about.html, served at /about. The old address /team still works: moorage.toml redirects it here.

Kept in the team's repository; deployed with Moorage.
