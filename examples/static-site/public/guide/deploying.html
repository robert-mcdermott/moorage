Deploying

Our apps run on our own Moorage server. This handbook is one of them.

Deploy an app

From the app's directory:

moor deploy

Moorage builds the app, shows the build as it happens, and switches to the new release once it is healthy. A static site like this one is swapped in at once.

Undo a deploy

moor rollback

The previous release is back in a moment.

Configure an app

moor env set --secret DATABASE_URL

Secrets are asked for, encrypted on the server, and never shown again.
